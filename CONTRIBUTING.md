# Contributing to Psychic Carnival

Thank you for your interest in contributing to the Psychic Carnival project! This document outlines the setup instructions for the Unreal Engine development environment, coding standards, branch naming conventions, and pull request guidelines.

## Setup Instructions for Unreal Engine Development Environment
1. **Install Unreal Engine**: Download the latest version of Unreal Engine from the [official website](https://www.unrealengine.com/download).
2. **Clone the Repository**: Open your terminal and run:
   ```bash
   git clone https://github.com/Kage-Jaguar/psychic-carnival.git
   cd psychic-carnival
   ```
3. **Open the Project**: Launch Unreal Engine and select the project by navigating to the cloned folder.
4. **Install Dependencies**: Ensure all required plugins and dependencies are installed by following the project documentation.

## Coding Standards
- **Language**: C++ is the primary language for Unreal Engine development.
- **Formatting**: Follow standard practices recommended by Unreal Engine regarding whitespace, naming conventions, and code organization.
- **Documentation**: Make sure to comment on your code and document your functions and classes appropriately.

## Branch Naming Conventions
- Use the following format for branch names: `feature/description` for new features, `bugfix/description` for bug fixes, and `hotfix/description` for urgent fixes.
- Example:
   - `feature/new-player-character`
   - `bugfix/fix-input-issue`

## Pull Request Guidelines
1. **Create a Pull Request**: Once your feature or fix is complete, push your branch to the repository and navigate to the Pull Requests tab in GitHub.
2. **Description**: Provide a detailed description of your changes and link any related issues.
3. **Review Process**: Wait for team members to review your pull request. Be open to feedback and make necessary changes.
4. **Merge**: After approval, you can merge your pull request into the main branch, if you have the necessary permissions.

Thank you for contributing and helping us improve the Psychic Carnival project!
