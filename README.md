# Psychic Carnival: VR Game Project

## Overview
Welcome to the Psychic Carnival VR Game project! This document will provide an overview of the project, including its goals and structure. This project aims to create an immersive Virtual Reality experience using Unreal Engine, integrating custom motion tracking suits and supporting MMO architecture with client-server communication.

### Key Features:
- Developed using Unreal Engine.
- Compatible with custom motion tracking suits.
- SteamVR support for enhanced user experience.
- Designed for Massive Multiplayer Online (MMO) gameplay using a client-server architecture.

For more detailed documentation, please refer to the respective directories.
